   - Blackout fabric over acoustic treatment

- Separation: Equal to radius (Helmholtz condition)

2. Measure field strength at center with gaussmeter
3. Adjust amplitude to achieve desired field strength
4. Map field uniformity across body position

## Troubleshooting

### Common Issues

#### Layer 2: Enclosure too hot

- Add ventilation fan (quiet, low EMF)
- Use mesh instead of solid panels
- Check for heat sources inside

#### Layer 3: PBM not feeling effective

- Verify wavelength with spectrometer app
- Check power density at skin distance
- Increase session duration
- Ensure skin is exposed (not through clothing)

#### Layer 4: Vibration too weak/strong

- Adjust amplifier gain
- Check transducer mounting (should be solid contact)
- Verify frequency (some frequencies cancel at certain positions)

#### Layer 5: PEMF field not uniform

- Verify Helmholtz condition (separation = radius)
- Check coil wiring (must be in phase)
- Map field with gaussmeter

#### Layer 8: Sensor data not syncing

- Check BLE connections
- Verify API keys for cloud services
- Check data format compatibility
